# User Guide and Troubleshooting: Nimbus Mesh Router AX6

## Setting up the router
Connect the WAN port to your modem with the supplied Ethernet cable, power on the router, and follow the setup in the Nimbus app. The light turns solid white when online.

## Router light meanings
- Solid white: online.
- Pulsing white: starting up or updating.
- Solid amber: no internet from the modem.
- Pulsing amber: mesh node cannot reach the main router.

## No internet (solid amber light)
1. Restart the modem first, wait 2 minutes, then restart the router.
2. Check the Ethernet cable is connected to the WAN port (marked with a globe).
3. If your internet provider requires PPPoE login, enter it in the app under Network > WAN.
4. If the modem works when a computer is connected directly, but the router still shows amber, contact support.

## Slow Wi-Fi speeds
Place the router in a central, elevated position away from microwaves and thick walls. Each node covers up to 2,500 sq ft; add a mesh node for larger homes. Make sure the router runs firmware 5.0 or later, which improved Wi-Fi 6 throughput. Run the speed test in the app to compare wired and wireless speed.

## Adding a mesh node
In the app choose Add node, place the node halfway between the router and the weak spot, and wait for the light to turn solid white.

## Factory reset
Hold the reset pin on the back for 10 seconds until the light pulses amber. All settings are erased.
